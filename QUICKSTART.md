# Quick Start Guide

## Installation & Running

### Windows:
```bash
cd To the proper location
start.bat
```

### macOS/Linux:
```bash
cd To the proper location
bash start.sh
```

### Manual:
```bash
cd To the proper location
npm install
npm run dev
```

Then open: **http://localhost:3000**

---

## Features Overview

### 🏠 Home Page (/)
- Browse all Magic cards in a responsive grid
- Left sidebar with all filter options
- Random card button in top right
- Card count display
- Load more pagination

### 🔍 Filters (Left Sidebar)

**Search**
- Type card name to search
- Auto-applies with 500ms debounce

**Sets**
- Dropdown with all Magic sets
- Multiple selection
- Ordered by newest first

**Mana Colors**
- 5 color buttons (W, U, B, R, G)
- Click to toggle on/off
- Select multiple colors

**Card Types**
- Creature, Instant, Sorcery, Enchantment, Artifact, Land, Planeswalker
- Checkboxes for multiple selection

**Rarity**
- Common, Uncommon, Rare, Mythic
- Checkboxes for multiple selection

**Mana Value**
- Toggle between "Exact" and "Range"
- Exact: Single input field
- Range: Min and Max input fields

**Clear All Button**
- Red button at top of sidebar
- Resets all filters instantly

### 🎲 Random Card Button
- Top right of page
- Purple button with dice emoji
- Takes you directly to random card detail page

### 🃏 Card Grid
- Responsive 1-4 column layout
- Lazy-loaded card images
- Click any card to see details
- Load More button at bottom

### 📖 Card Detail Page (/card/[id])

**Left Side**
- High-res card image
- For double-sided cards: toggle buttons to switch faces

**Right Side**
- Card name and type
- Mana cost, CMC, P/T (if applicable)
- Set name and release date
- Card rarity
- Full card text
- External links:
  - Scryfall (official database)
  - Gatherer (official reference)
  - TCGPlayer (buy cards)
  - EDHREC (EDH recommendations)
  - Archidekt (deck building)

## API Information

**Scryfall API** - Free, no authentication required
- Base: https://api.scryfall.com
- Rate limit: 60 requests/second
- All card data fetched in real-time

---

## Performance Tips

- First load caches set data for faster filtering
- Images are lazy-loaded (load only when visible)
- Search has debounce to reduce API calls
- Use specific filters for better performance

## Troubleshooting

**Problem: Port 3000 already in use**
```bash
# Windows
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# macOS/Linux
lsof -i :3000
kill -9 <PID>
```

**Problem: npm command not found**
- Install Node.js from https://nodejs.org/
- Restart terminal after installation

**Problem: Cards not loading**
1. Check internet connection
2. Check browser console (F12) for errors
3. Verify Scryfall API status

**Problem: Images not showing**
- Some older cards may not have images
- Try reloading the page
- Images are cached by browser

## File Changes

Never manually edit:
- node_modules/ (reinstall with `npm install`)
- .next/ (generated by Next.js)

Safe to customize:
- `lib/api.ts` - Change API queries
- `components/*` - Change UI
- `tailwind.config.ts` - Change colors
- `app/globals.css` - Change styles

## Environment Variables

Edit `.env.local` to customize:
- `NEXT_PUBLIC_SCRYFALL_API_BASE` - API endpoint
- `NEXT_PUBLIC_CARDS_PER_PAGE` - Cards per load
- `NEXT_PUBLIC_SEARCH_DEBOUNCE_MS` - Search delay
